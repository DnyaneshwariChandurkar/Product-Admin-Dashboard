# Product Admin Dashboard

A responsive Product Admin Dashboard built using React.js, Tailwind CSS, Axios, and DummyJSON API.

## Features

- Admin Login
- Product Listing
- Product Search
- Category Filter
- Price Range Filter
- Product Sorting
- Pagination
- Product Details
- Add Product
- Edit Product
- Delete Product
- Delete Confirmation
- Loading and Error States
- Success and Error Toast Notifications
- Responsive UI

## Technologies Used

- React.js
- Tailwind CSS
- Axios
- React Router DOM
- React Hot Toast
- DummyJSON API
- Vite

This project uses DummyJSON API for authentication and product management.
